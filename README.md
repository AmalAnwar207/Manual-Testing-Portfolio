# Manual Testing Portfolio – SauceDemo

## Project Overview
This repository contains a manual software testing project for the SauceDemo web application.

The project demonstrates practical application of software testing fundamentals, including test planning, test case design, test execution, and defect reporting.

## Application Under Test
- **Application:** SauceDemo
- **URL:** https://www.saucedemo.com/
- **Testing Type:** Manual Testing
- **Test Environment:** Web Browser
- **Project Status:** In Progress

## Testing Scope
The project covers the following functionalities:
- Login and Authentication
- Product Listing
- Shopping Cart Management
- Checkout Process
- Input Validation and Error Handling

## Repository Structure

- `README.md` – Project overview and summary.
- `Test-Plan.md` – Testing objectives, scope, and approach.
- `Test-Cases.md` – Test scenarios, steps, and expected results.
- `Test-Execution-Report.md` – Test execution summary and results.
- `Bug-Reports.md` – Documented defects.

## Testing Approach
1. Review application functionalities.
2. Identify test scenarios.
3. Design test cases with expected results.
4. Execute test cases.
5. Compare actual results with expected results.
6. Document defects and test outcomes.
