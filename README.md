
# Manual Testing Portfolio

A beginner QA portfolio demonstrating practical Manual Testing concepts through test scenarios, test case design, test execution, and bug reporting.

## Project Overview

This project focuses on testing the [SauceDemo](https://www.saucedemo.com/) e-commerce demo application.

## Testing Scope

- Login and Authentication
- Product Listing
- Shopping Cart
- Checkout Process
- Input Validation

## Testing Types

- Functional Testing
- Positive and Negative Testing
- UI Testing
- Form Validation

## Project Documents

| Document | Description |
|---|---|
| Test Cases | Test scenarios, steps, expected results, and actual results |
| Bug Reports | Documentation of defects identified during testing |

## Tools

- Jira – Issue tracking practice
- Google Sheets / Excel – Test case documentation
- Browser DevTools – Basic inspection

## Project Status

Manual testing practice project – ongoing.

Test results and bug reports will be documented based on actual test execution.
